Projects

  • End-to-End Manipulation Pipeline with LeRobot and smolVLA

    Collected teleoperation datasets with SO-101 arms, uploaded data to Hugging Face, fine-tuned a pretrained smolVLA model, and evaluated learned behavior under camera and object-placement changes.

    • Compared fixed-view and moving-view datasets for a wet-tissue stacking task.
    • Defined a subtask-level evaluation rubric for approach, grasp, lift, move, and place.
    • Observed strong dependence on wrist-camera input and failures under randomized object placement.
  • Diffusion Policy Deployment and EE-Space Dataset Conversion

    Set up a real-robot block pick-and-place experiment, collected 100 demonstrations, started Diffusion Policy training, deployed a 40K checkpoint, and converted joint-space trajectories toward end-effector-space representations.

    • Investigated action-chunk latency and discontinuous deployment behavior.
    • Used forward kinematics to convert trajectory data and identified rotation-vector discontinuities.
    • Considered quaternion orientation as a more stable representation for learning.
  • Piper Calibration and Cross-View Alignment

    Adapted RAIDEN calibration tools to a Piper arm, collected calibration poses, ran ChArUco-based calibration, and visualized camera frames and RGB-D point clouds in Open3D.

    • Added Piper-specific backend logic where the original toolkit assumed a YAM bimanual robot.
    • Debugged board detection, marker dictionary mismatch, marker sizing, RealSense setup, and transform-chain interpretation.
    • Verified scene-camera and wrist-camera placement using base-frame, FK, and hand-eye transforms.
  • Human-in-the-Loop Joint-Delta Intervention

    Modified a Piper Diffusion Policy intervention path so a human operator could correct policy execution through joint-space delta teleoperation.

    • Replaced less accurate delta end-effector intervention with a joint-delta control path.
    • Reduced reliance on forced leader/follower synchronization during intervention.
    • Preserved the existing policy and recording structure while changing the corrective-control mechanism.
