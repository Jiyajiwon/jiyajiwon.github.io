I set up a camera calibration pipeline for a robot manipulation system using a Raiden-based calibration workflow. The setup included a wrist-mounted camera and an external scene camera, and the goal was to align camera observations with the robot frame for real-world manipulation experiments.

The project involved calibration board setup, pose collection, and result inspection, along with visualization to check alignment between views. This calibration setup was used to support perception and observation alignment in downstream robot experiments.
